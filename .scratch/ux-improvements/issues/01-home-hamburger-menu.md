# 01: Hamburger Menu na Stronie Głównej

**What to build:** Dodanie komponentu `HamburgerMenu` w lewym górnym rogu strony głównej, do którego przeniesiony zostanie panel użytkownika (tokeny, prawa nauczyciela, wylogowanie).

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Utworzenie pustego komponentu `HamburgerMenu` (ikona hamburgera)
- [ ] Przeniesienie logiki panelu użytkownika ze strony głównej do tego komponentu
- [ ] Zapewnienie poprawnego rozwijania menu po kliknięciu
- [ ] Testy jednostkowe/integracyjne (TDD) potwierdzające, że menu się otwiera i zawiera odpowiednie elementy
